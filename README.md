# Kurdistan Mountain Honey — Free Website

This is a static, mobile-friendly website ready for free hosting.

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html` with your business email.
2. If you have the laboratory report, add a PDF as `assets/lab-report.pdf` and change the quality section to link to it.
3. Confirm the exact wording of the 98.2% laboratory result and whether you hold a recognized organic certification. Avoid describing the honey as "certified organic" unless you have the relevant certification.

## Free hosting
Recommended: GitHub Pages. Create a free GitHub repository, upload the contents of this folder, enable Pages from the repository's Settings, and use the free `username.github.io` address.

Other free static hosts include Netlify and Cloudflare Pages.

## Domain
A truly free custom `.com` domain is generally not available. Free hosting normally gives you a free subdomain such as `username.github.io`. You can later connect a paid custom domain if you want a professional `.com` address.
